# 🔳 QR Code Component

Este es un **componente de código QR** diseñado con HTML y CSS. Es un desafío del sitio [Frontend Mentor](https://www.frontendmentor.io) que ayuda a mejorar habilidades en desarrollo web.  

## 🎨 Vista Previa

![Vista previa del componente QR](preview.jpg)

## 🚀 Tecnologías Utilizadas

- 🏗 **HTML5** - Estructura semántica.  
- 🎨 **CSS3** - Estilos modernos y diseño responsivo.  

## 📂 Estructura del Proyecto
```bash
qr-code-component-main/
│── index.html # Página principal con el componente
│── styles.css # Estilos del componente
│── images/ # Imágenes usadas (como el código QR)
│── README.md # Archivo de documentación
```

## 🎯 Características

✅ **Diseño limpio y moderno**.  
✅ **Totalmente responsivo** 📱💻.  
✅ **Fácil de personalizar** - Cambia el código QR y los textos fácilmente.  

## 🚀 Cómo Usarlo

1. **Descarga o clona el repositorio**  
   ```sh
   git clone https://github.com/AldousTheWise/qr-code-component-main.git

2. **Abre index.html en tu navegador.**
3. **Personaliza el contenido en index.html y los estilos en styles.css.**
4. Sube tu componente a GitHub Pages para compartirlo en línea. 🌍

## 🛠️ Personalización
Para modificar el contenido:
- Reemplaza la imagen del código QR en images/qr-code.png.
- Cambia el título y descripción en index.html.
- Ajusta los colores y tipografías en styles.css según tu preferencia.
